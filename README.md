# Air Analyzer

Air analyzer flutter app

Built for esp32 S3

- Temperature
- Humidity
- CO2

## Description

Air analyzer that measures Temperature, Humidity and CO2
and controls relays based on the set parameters.

### Working Ranges

- co2 -- 400-5000ppm
